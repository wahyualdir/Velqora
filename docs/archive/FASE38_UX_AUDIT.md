# FASE 38 — UX AUDIT, "NO AI SLOP" & CALM ACADEMIC EXPERIENCE

## 1. Principles of Calm Academic Software
1. **Simple by Default, Deep on Demand**:
   - Primary surface: Current conditions, nearest deadline, active conflicts, today's workload, and top actionable recommendation.
   - Secondary surface: Academic health, workload distribution tables, and learning pattern trends.
   - Advanced surface: What-If simulation sandbox, 12-question transparency breakdown, and historical calibration logs.
2. **Removal of AI Buzzwords**:
   - Replaced terms like "AI magic", "neural intelligence", and "generative wizardry" with precise academic language ("penyesuaian jadwal", "keseimbangan beban", "bebas bentrok").
   - Removed decorative sparkles icons in favor of functional semantic icons (`Activity`, `ArrowRight`, `CheckCircle2`).
3. **Transparent Cause and Effect**:
   - Recommendations explicitly state **Alasan**, **Dampak Perubahan**, and **Skor Kecocokan**.
   - User maintains full agency via `[Tinjau]` and `[Jelaskan]` progressive controls.
